# ethan_xie 的博客使用指南

网站：https://xiegaoxiao.github.io/

本地目录：`D:\myapp\myblog`，源码分支：`hexo-source`。

## 本地预览

推荐 Node.js 22；本次本地构建也已验证 Node.js 24。

```powershell
cd D:\myapp\myblog
npm ci
npm run server
```

访问 http://localhost:4000/。修改主题 Pug 模板后需要重启预览服务。

## 写文章

```powershell
npm run new -- "我的第一篇文章"
```

编辑 `source/_posts/` 中新生成的 Markdown 文件。Front matter 可填写 `title`、`date`、`tags`、`categories`、`cover`；新文章默认使用稳定的短链接。旧文章通过 `permalink` 保留原有路径，请保留这一字段。

## 发布

```powershell
npm run build
git add .
git commit -m "更新博客文章"
git push origin hexo-source
```

GitHub Actions 自动安装依赖、构建并部署到 GitHub Pages。无需个人访问令牌、SSH 密钥或手动上传 `public/`；不要运行旧模板的 `hexo deploy`。

## 修改个人信息

- `_config.yml`：博客名称、作者、简介、语言、时区、网址。
- `_config.fomalhaut.yml`：头像、首页大图、导航、社交链接、侧栏。
- `source/personal/about/index.md`：关于页面。
- `source/_data/link.yml`：推荐站点。
- `source/assets/`：上传自己的封面、头像和其他素材。

当前头像取自 GitHub，评论和 AI 助手默认关闭；文章搜索使用本站生成的 `search.xml`。模板示例文章保存在 `docs/examples/`，不作为个人文章发布。

## 旧文章与回滚

原仓库的 15 篇文章已从 Atom feed 恢复为 Markdown，迁移清单见 `docs/legacy-migration.json`。恢复自生成 HTML，排版可能与原稿略有差异，代码和图片已保留。

旧 `main`、`master` 分支保留不动。若要恢复旧站，到仓库 Settings → Pages 把 Source 改为 Deploy from a branch，选择 `main` 与根目录 `/`。源码工作区的 `.legacy-site/`、`.theme-template/` 和 `.qa/` 是本地备份与检查材料，已被 Git 忽略。

主题来源：[Fomalhaut](https://github.com/fomalhaut1998/hexo-theme-fomalhaut)，遵循仓库附带的 Apache-2.0 许可证；主题升级时应保留本站对页脚及本地搜索的调整。
