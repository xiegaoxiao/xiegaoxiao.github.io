### bean的基础配置

1.  `name` 可以起别名 如果有多个别名 用**空格,逗号,分号**分隔开
    
    ```xml
    <bean id="userDao" name="dao udao" class="com.itheima.dao.impl.UserDaoImpl"/>
        <bean id="userService" class="com.itheima.service.impl.UserServiceImpl">
            <property name="userDao" ref="dao"/>
     </bean>
    ```
    
2.  Spring默认造的对象都是**单例的(singleton)** 如果想造多例的可以使用`scope`属性设置为**prototype**
    
    ```xml
    <bean id="userDao" name="dao udao" class="com.itheima.dao.impl.UserDaoImpl" scope="prototype"/>
    ```
    

### bean作用范围说明

-   为什么bean默认为单例?
-   适合交给容器进行管理的bean
    -   表现层对象
    -   业务层对象
    -   数据层对象
    -   工具对象
-   不适合交给容器进行管理的bean
    -   封装实体的域对象

### bean的实例化

-   bean本质就是对象,创建bean使用**构造方法**完成
    
    ```java
    public class UserDaoImpl implements UserDao {
        public UserDaoImpl(){ // 这里private也能用内部原理是反射
            System.out.println("我是UserDao的构造方法");
        }
        @Override
        public void save() {
            System.out.println("我是UserDao的实现类");
        }
    }
    ```
    

#### 使用静态工厂创建对象(了解)

```java
public class OrderDaoFactory {
    public static OrderDao getOrderDao(){
        return new OrderDaoImpl();
    }
}

---
public class OrderDaoImpl implements OrderDao {
    @Override
    public void save() {
        System.out.println("OrderDao 对象已创建");
    }
}

---
public class TestApp1 {
    @Test
    public void test1(){
        ApplicationContext app = new ClassPathXmlApplicationContext("applicationContext.xml");
        //通过静态工厂创建对象
        OrderDao orderDao = (OrderDao) app.getBean("orderDao");
        orderDao.save();
    }
}
```

-   xml配置

```xml
<bean id="orderDao" class="com.itheima.factory.OrderDaoFactory" factory-method="getOrderDao"/>
```

#### 使用实例工厂实例化bean(了解)

-   和上面差不多就是要多new一个工厂对象

```xml
<bean id="orderDaoFactory" class="com.itheima.factory.OrderDaoFactory"/>
   <bean id="orderDao" factory-bean="orderDaoFactory" factory-method="getOrderDao"/>
```

#### 使用FactoryBean实例化bean(实用)

```java
public class OrderDaoFactoryBean implements FactoryBean<OrderDao> {
    @Override
    public OrderDao getObject() throws Exception {
        System.out.println("我是工厂方法");
        return new OrderDaoImpl();
    }

    @Override
    public Class<?> getObjectType() {
        return OrderDao.class;
    }

    @Override
    public boolean isSingleton() { //是否是单例,可不写
        return true;
    }
}
```

-   xml配置

```xml
<bean id="orderDao" class="com.itheima.factory.OrderDaoFactoryBean"/>
```

### bean的生命周期

-   生命周期:从创建到消亡的完整过程
-   bean生命周期:bean从创建到销毁的整体过程
-   bean生命周期控制:在bean创建后到销毁前做一些事情

```java
public class OrderDaoImpl implements OrderDao {
    @Override
    public void save() {
        System.out.println("OrderDao 对象已创建");
    }

    public void init(){
        System.out.println("init...");
    }
    public void destory(){
        System.out.println("destory...");
    }
}
---
public class TestApp1 {
    @Test
    public void test1(){
        ClassPathXmlApplicationContext app = new ClassPathXmlApplicationContext("applicationContext.xml");
        //通过静态工厂创建对象 
        OrderDao orderDao = (OrderDao) app.getBean("orderDao");
        orderDao.save();
        //方法1 直接关闭
        //app.close();
        //方法2 设置关闭钩子
        app.registerShutdownHook();

    }
}
```

```xml
<bean id="orderDao" class="com.itheima.dao.impl.OrderDaoImpl" init-method="init" destroy-method="destory" />
```

-   实现spring提供的接口来销毁(了解)

```java
public class OrderDaoImpl implements OrderDao, InitializingBean, DisposableBean {
    @Override
    public void save() {
        System.out.println("OrderDao 对象已创建");
    }

    @Override
    public void destroy() throws Exception {
        System.out.println("bean destroy");
    }

    @Override
    public void afterPropertiesSet() throws Exception {
        System.out.println("bean init");
    }
}
```

#### bean生命周期

-   初始化容器
    1.  创建对象(内存分配)
    2.  执行构造方法
    3.  执行属性注入(set操作)
    4.  **执行bean初始化方法**
-   使用bean
    1.  执行业务操作
-   关闭/销毁容器
    1.  **执行bean销毁方法**

#### bean销毁时机

-   容器关闭前触发bean的销毁
-   关闭容器方式:
    -   手动关闭容器
        -   **ClassPathXmlApplicationContext** 接口**close**()操作
    -   注册关闭钩子,在虚拟机退出前先关闭容器再退出虚拟机
        -   **ClassPathXmlApplicationContext** 接口**registerShutdownHook**()操作
