# AOP是什么

-   AOP即面向切面编程 (Aspect-Oriented Programming), 是一种编程范式
-   作用: 在不修改源代码的情况下做功能增强(无入侵式编程)
-   由来: 其实是对**继承**(**提高代码复用性**)和**多态**(**灵活配置**)的补充, 假如我出现了这样一种情况我想给某一个类加一个打印日志的功能:
    -   如果采用通过继承父类来实现其实并不满足`Dog is an animal`这样的关系
    -   如果采用通过实现接口来实现代码又会出现**冗余**(Dao层,Service层)都要进行实现

## AOP的重要概念

1.  **关注点**: 就是我们要为某个类添加的这样一个方法(如日志管理,事务管理)
2.  **连接点**: 程序的某段特定代码(我们要为其前或后添加功能的一段代码)
3.  **通知**: 在特定的连接点执行的动作
4.  **切入点** : 我通知应该连接到哪些连接点
5.  **目标对象**: 被通知的对象
6.  **切面**: 切入点 + 通知

# AOP的经典实现

## 环境配置

-   pom.xml 文件下添加如下依赖

```xml
<dependency>
     <groupId>org.springframework</groupId>
     <artifactId>spring-context</artifactId>
     <version>5.0.5.RELEASE</version>
   </dependency>
   <dependency>
     <groupId>org.springframework</groupId>
     <artifactId>spring-aop</artifactId>
     <version>5.0.5.RELEASE</version>
   </dependency>

   <dependency>
     <groupId>org.aspectj</groupId>
     <artifactId>aspectjrt</artifactId>
     <version>1.9.6</version> 
   </dependency>
   <dependency>
     <groupId>org.aspectj</groupId>
     <artifactId>aspectjweaver</artifactId>
     <version>1.9.6</version> 
   </dependency>
   <dependency>
     <groupId>junit</groupId>
     <artifactId>junit</artifactId>
     <version>4.13.2</version>
   </dependency>
   <dependency>
     <groupId>org.springframework</groupId>
     <artifactId>spring-test</artifactId>
     <version>5.0.5.RELEASE</version>
   </dependency>
```

-   创建`com.xxx.config` 创建SpringConfig配置类

```java
@Configuration  // 声明他是个配置文件
@ComponentScan("com.hugong") //包扫描换成自己的
@EnableAspectJAutoProxy  // 启用切面自动代理
public class SpringConfig {
}
```

-   创建`com.xxx.dao`,创建Dao接口 并实现

```java
@Repository
public class UserDaoImpl implements UserDao {
    @Override
    public void query() {
        System.out.println("查询方法执行...");
    }

    @Override
    public void add() {
        System.out.println("添加方法执行...");
    }

    @Override
    public void delete() {
        System.out.println("删除方法执行...");
    }

    @Override
    public void update() {
        System.out.println("更新方法执行...");
    }
}
```

-   创建`com.xxx.service`,创建Service接口并实现

```java
@Service
public class UserServiceImpl implements UserService {
    @Autowired
    private UserDao userDao;
    @Override
    public void query() {
        userDao.query();
    }

    @Override
    public void add() {
        userDao.add();
    }

    @Override
    public void delete() {
        userDao.delete();
    }

    @Override
    public void update() {
        userDao.update();
    }
}
```

-   创建`com.xxx.aspect` 包并创建 `MyAspect` 类

```java
@Component
@Aspect
public class MyAspect {

    //切入点
    @Pointcut("execution( * com.hugong.service.*.*(..))")
    public void myPointCut(){
//解释 表示 Service包下所有类所有方法 (..) 表示任意参数类型
    }

    //通知(环绕) 其中 ProceedingJoinPoint 返回值类型是 Object 
    @Around("myPointCut()")
    public Object record(ProceedingJoinPoint proceedingJoinPoint) throws Throwable {
        System.out.println("通知 前");
        Object proceed = proceedingJoinPoint.proceed(); //这句是必要的
        System.out.println("通知 后");
        return proceed;
    }

}
```

-   创建测试类

```java
@RunWith(SpringJUnit4ClassRunner.class)
@ContextConfiguration( classes =  SpringConfig.class)
public class Test01 {
    @Autowired
    private  UserService userService;
    @Test
    public  void test01(){
        userService.add();
    }
}
```
