# 容器

## 创建容器

1.  通过类路径来加载配置文件
    
    ```java
    //第一种获取方式(常用)
    ApplicationContext app = new ClassPathXmlApplicationContext("配置文件.xml");  
    ```
    
2.  文件路径加载配置文件
    
    ```java
    //从文件系统获取(不好用)
    ApplicationContext app2 = new FileSystemXmlApplicationContext("绝对路径");
    ```
    
3.  加载多个文件
    
    ```java
    ApplicationContext app = new ClassPathXmlApplicationContext("bean1.xml,bean2.xml");  
    ```
    

## 获取bean

-   bean获取的三种方式

1.  通过`id`来获取
    
    ```java
    DataSource dataSource = (DataSource) app.getBean("dataSource");
    ```
    
2.  通过类名来获取
    
    ```java
    DataSource dataSource3 = app.getBean(DataSource.class);
    ```
    
3.  通过类名和id来获取
    
    ```java
    DataSource dataSource2 = app.getBean("dataSource",DataSource.class);
    ```
    

## 容器类层次结构

-   BeanFactory(顶层接口)
    -   ApplicationContext(常用接口)
        -   ConfigurableApplicationContext **(提供关闭容器接口)**
        -   ClassPathXmlApplicationContext(常用实现类)
        -   FileSystemXmlApplicationContext(常用实现类)

## BeanFactory初始化

-   BeanFactory创建完毕后,所有的bean均为**延迟加载**

# 容器核心总结

## 容器相关

-   BeanFactory是IoC容器的顶层接口,初始化BeanFactory对象时,加载的bean延迟加载
-   ApplicationContext接口是Spring容器的核心接口,初始化时bean立即加载
-   ApplicationContext接口提供基础的bean操作相关方法,通过其他接口扩展其功能
-   ApplicationContext接口常用初始化类
    -   ClassPathXmlApplicationContext
    -   FileSystemXmlApplicationContext

## bean相关

```xml
<bean 
id="orderDao"                                             bean的id
class="com.itheima.dao.impl.OrderDaoImpl"                 bean的类型
name="oDao"                                               bean的别名
init-method="init"                                        生命周期初始化方法
destroy-method="destroy"                                  生命周期销毁方法
autowire="byType"                                         自动装配类型
factory-method="getInstance"                              bean工厂方法
factory-bean="com.itheima.factory.orderDaoFactory"        示例工厂bean
lazy-init="true"                                          控制bean延迟加载
scope="prototype"                                         控制bean实例数量
/>
```
