设定一个目标之后，还需要回答更具体的问题：距离截止日期还有多久？剩下的任务每天要做多少？今天的安排是否已经超过可用时间？

我的开源项目 [TimeCalc](https://github.com/xiegaoxiao/timecalc) 把这些信息放进一个 Windows 桌面应用里。它围绕目标、每日执行和进度反馈组织功能，业务数据存放在本地，不需要先注册云端账号。

<!-- more -->

## 从一个目标开始

可以把使用过程理解为五步：创建目标、设置可用学习日、拆分任务、检查负载、执行并记录完成情况。

例如，还剩 20 个可用学习日，需要完成预计 40 小时的任务，那么建议日均投入约为 2 小时。这只是一个说明计算思路的例子，实际安排还需要结合课程、休息日和任务的真实耗时。

TimeCalc 提供目标与阶段里程碑、今日任务与逾期处理、按日排程和重复任务。计划调整时，可以改期或延期；完成任务后，再通过燃尽趋势和完成热力图查看推进情况。功能说明见 [项目 README](https://github.com/xiegaoxiao/timecalc/blob/f39b348946adcd3eabf14b3e158ad532f54ff31e/README.md)。

![TimeCalc 今天页面，展示目标与今日执行信息](https://raw.githubusercontent.com/xiegaoxiao/timecalc/f39b348946adcd3eabf14b3e158ad532f54ff31e/docs/ui-refactor-shots/01-today.png)

## 课表与日历互通

学生的时间安排往往同时包含课程和自主学习任务。TimeCalc 的课表支持教学周、节次和单双周信息，并可导入 `.ics` 或 JSON 文件；计划也支持 iCalendar 导入、导出。

这样可以把固定课程和可调整的任务放在同一个日常工作流里。重复任务支持按天、按星期、每隔 N 天以及间隔序列生成。间隔序列可以用于复习排期，但具体间隔仍应按自己的学习情况调整。

## v2.0.0 的一次取舍

截至本文发布，最近的正式版本是 [v2.0.0](https://github.com/xiegaoxiao/timecalc/releases/tag/v2.0.0)，发布于 2026 年 10 月 5 日。

这次更新采用暖橙与冷藏青的配色，并统一主要页面和对话框的视觉组件。同时，版本记录明确移除了未发布的智能重排草稿、任务耗时图、计划年视图和部分重复实现，保留目标、今日执行、改期与进度反馈的核心流程。

对一个个人工具来说，这个版本的看点既包括界面变化，也包括功能范围的收敛。详细变更和项目自身的验证记录见 [发布说明](https://github.com/xiegaoxiao/timecalc/releases/tag/v2.0.0)。

## 本地数据与技术栈

项目使用 Flutter 构建桌面界面，Riverpod 管理状态，GoRouter 处理路由，SQLite 与 drift 保存业务数据，fl_chart 绘制图表。依赖清单见 [pubspec.yaml](https://github.com/xiegaoxiao/timecalc/blob/f39b348946adcd3eabf14b3e158ad532f54ff31e/pubspec.yaml)。

数据可以导出为 `.timecalc` 备份，覆盖恢复前会创建安全副本。自动备份在应用运行期间执行，默认保留最近 7 份，具体实现见 [自动备份服务](https://github.com/xiegaoxiao/timecalc/blob/f39b348946adcd3eabf14b3e158ad532f54ff31e/lib/features/backup/data/auto_backup_service.dart)。

## 下载与运行

在 [v2.0.0 下载页面](https://github.com/xiegaoxiao/timecalc/releases/tag/v2.0.0) 获取 `timecalc-v2.0.0-windows-x64.zip`，解压后运行 `timecalc.exe`。

如果想阅读和构建源码，可以从下面的命令开始。Flutter 环境需要满足仓库声明的 Dart SDK 约束，并配置 Windows 桌面构建工具。

```powershell
git clone https://github.com/xiegaoxiao/timecalc.git
cd timecalc
flutter pub get
flutter run -d windows
```
